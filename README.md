Welcome to my personal portfolio repository!

## 🌐 Live Website

[**Visit My Portfolio**](https://joeld-portfolio.vercel.app/)

## ✨ Website Sections

- **About Me** – A brief introduction and background.
- **Skills** – My technical skills and areas of interest.
- **Projects** – A showcase of my academic and personal projects.
- **Education** – My academic journey.
- **Contact** – Ways to connect with me.

## 🛠️ Technologies Used

- WordPress
- Elementor
- HTML
- CSS
- Vercel (Deployment)

## 🚀 Deployment

The website was created using WordPress and Elementor, exported as a static website, and deployed using Vercel.

## 📂 Repository Structure

- `index.html` – Main website page.
- `wp-content/` – Website assets, stylesheets, scripts, and media.
- `wp-includes/` – Exported WordPress resources.
